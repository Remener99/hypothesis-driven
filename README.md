# HypoLab — генератор и трекер гипотез для маркетологов маркетплейсов

**Стек:** React 18 + Vite + Tailwind + TanStack Query + Recharts · Node.js (Express 5) + SQLite (better-sqlite3) · SheetJS (xlsx) · JWT в httpOnly-cookie.

## Запуск
```bash
npm install
npm run build             # собрать фронтенд в dist/
npm run server            # API + SPA на http://localhost:3001
# режим разработки: node server/index.js  +  npx vite (порт 5173, /api проксируется)
```
Демо-вход: **demo@hypolab.ru / demo1234**. БД создаётся в `data/hypolab.db`, демо-данные засеваются при первом запуске
(и при регистрации с галочкой «Заполнить демо-данными»). Сброс: Настройки → «Сбросить демо-данные».

## Возможности
- **Пошаговый генератор** (5 шагов): контекст → узкое место воронки AARRR → идея из библиотеки 24 тактик (с ICE) → SMART-формулировка с live-чеклистом и автоподсчётом baseline из данных → ICE и план HADI.
- **Бэклог**: канбан с drag&drop по статусам (Запланирована / Тестируется / Завершена / Масштабируется / Отменена) и таблица; поиск, фильтры, сортировка.
- **CRUD** гипотез и датасетов, inline-редактирование, дублирование, история изменений.
- **Оптимистичные обновления**: смена статуса, редактирование, создание, удаление (с отменой в течение 5 с) — с откатом при ошибке.
- **Анализ «до / во время / после»**: вердикт по целевой метрике, Welch t-test, проверка устойчивости эффекта, детекция искажающих факторов (изменение цены, out-of-stock, рост рекламы), график с зонами периодов.

## Парсинг Excel (`server/excel.js`)
1. Все листы читаются SheetJS; для каждого в первых 25 строках ищется строка-заголовок.
2. Определяется структура: **long** (дни в строках, опц. × артикул) или **wide** (метрики в строках, даты в столбцах). Побеждает лист/вариант с наибольшим числом распознанных метрик.
3. Заголовки нормализуются (регистр, ё→е, единицы измерения, пунктуация) и сопоставляются со словарём `shared/metrics.json` (~150 синонимов: «Заказали, шт», «Посещения карточки товара», «ДРР»…) — точное совпадение → вхождение → совпадение токенов, с оценкой уверенности.
4. Даты: объекты Date, серийные числа Excel, ISO, dd.mm.yyyy, dd/mm/yy, «1 сентября 2026», «сен 2026», диапазоны «01.09–07.09.2026» (определяется шаг: день/неделя/месяц).
5. Числа: «1 234,5 ₽», «12,5%», «(300)», 1.234,56 / 1,234.56. Проценты → доли.
6. Строки агрегируются по (дата, артикул); итоговые строки без даты отбрасываются с предупреждением; конверсии, CTR, ДРР, средний чек и % выкупа досчитываются из базовых метрик.
7. Двухэтапный импорт: предпросмотр с ручной правкой сопоставления → сохранение.

Примеры файлов: `samples/` (WB-воронка, Ozon с датами в столбцах, шаблон).
